## 確認した主張

- **C-ALLOCATION**: 固定FLOPs予算の制約下で、損失を小さくするパラメータ数と学習トークン数の配分を探す。 該当: §1 Eq.(1), §3, §3.2（取得表示の行 96–100, 123–125, 135–140、chinchilla-body）。
- **C-LOSS**: 二変数の経験式は E + A/N^α + B/D^β。下限に対応する項と、規模・データに依存する項を分ける。記事の一変数式そのものの引用ではない。 該当: §3.3 Eq.(2)（取得表示の行 142–147、chinchilla-body）。
- **C-GROWTH**: 計算予算が増えるときの最適なN・Dの成長率は近い。NとDの数値や単位が等しいという意味ではない。 該当: §3.3 Eq.(4), §3.4 Table 2（取得表示の行 154–171、chinchilla-body）。
- **C-FLOPS**: 計算量の単位はFLOPs。埋め込みを含む演算数と6ND概算を比較し、逆伝播を順伝播の約2倍としている。 該当: Appendix F, Table A4（取得表示の行 483–545、chinchilla-body）。
- **K-FLOPS**: 埋め込みを除く学習演算数を、トークン当たり約6Nとして概算する。文脈依存項などを省く条件がある。FLOPsを料金・時間・電力そのものとは定義していない。 該当: §1.3, §2.1 Table 1 / Eq.(2.2)直後（取得表示の行 173–197, 208–230、kaplan-body）。

## 置換との対応

before/afterは承認済み計画JSONの文字列をそのまま収録しています。

### C2-1: スケーリング則の系譜 / 式の読み下し

変更前:

```text
$N$ を 10 倍しても損失は一定の割合でしか下がらない(収穫逓減)
```

変更後:

```text
$N$ を 10 倍すると、下限からの差 $L-L_\infty$ が一定の割合で小さくなる(収穫逓減)
```

根拠対応: C-LOSS。判定: supported。

記事の既存式のR(N)=L(N)−L∞=(Nc/N)^αNに対し、R(10N)=10^(−αN)R(N)。倍率はRに掛かる。Chinchillaの二変数式でDを固定する場合、Nに関する下限はE+B/D^βとなるので、L∞を無条件に論文のEと同一視しない。

### C2-2: スケーリング則の系譜 / Chinchilla箇条書き

変更前:

```text
固定の計算予算 $C$ の下で損失を最小化するには、**$N$ と $D$ をほぼ同じ割合で一緒に増やすべき**、という修正。
```

変更後:

```text
固定の計算予算 $C$ の下で損失を最小化する $N$ と $D$ の配分を調べ、**計算予算を増やすときには $N$ と $D$ をほぼ同じ割合で一緒に増やすべき**、とした修正。
```

根拠対応: C-ALLOCATION, C-GROWTH。判定: supported。

固定予算内の配分と、予算増加時の成長を分ける既承認差替えを採用できる。

### C2-3: スケーリング則の系譜 / Mermaidラベル

変更前:

```text
計算最適(N と D を均等に)
```

変更後:

```text
計算最適(N と D の配分)
```

根拠対応: C-ALLOCATION, C-GROWTH。判定: supported。

本文と同じ配分という意味に統一するラベル訂正。Mermaidのノード・矢印・構造は変えない。

### C2-4: 学習の計算量の目安 / 読み下し

変更前:

```text
計算量(= コスト・時間・電力)が比例して増える
```

変更後:

```text
計算量(FLOPs)が比例して増える
```

根拠対応: K-FLOPS, C-FLOPS。判定: supported。

演算回数・通貨・経過時間・電力は別の物理量。既存の後続文が実コストのハードウェア・並列化効率依存を説明するため、追加段落なしで訂正できる。

### C2-5: 学習の計算量の目安 / 計算最適の文

変更前:

```text
計算最適の含意「$N$ と $D$ を均等に」は、この $C$ を固定したうえで損失を最小化する配分の話です。
```

変更後:

```text
固定した $C$ の下では、損失を最小化する $N$ と $D$ の配分を選びます。$N$ と $D$ をほぼ同じ割合で増やすという含意は、計算予算を増やす場合の話です。
```

根拠対応: C-ALLOCATION, C-GROWTH, C-FLOPS。判定: supported。

6ND概算の下でC固定ならNDは一定。同じ倍率kで両方を増やすとCはk²倍となる。これは概算式の帰結で、普遍的な実測コスト則ではない。


変更後:

```text
計算最適(Chinchilla)。計算予算に応じた $N$ と $D$ の配分
```

根拠対応: C-ALLOCATION, C-GROWTH。判定: supported。
