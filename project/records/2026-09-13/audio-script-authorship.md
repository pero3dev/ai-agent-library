# 音声台本の共同編集者を引き継ぐ

2026-09-13。音声制作を続ける中で、Codexが初稿を書き、Claudeが独立レビューだけを行う場合も、公開処理が一律にClaudeを共同編集者へ記載することを確認しました。台本を編集したAgentと、レビューだけを行ったAgentを区別して記録します。

## 作業契約

- 目的: 台本ごとの実際の編集参加を、修正・中断再開・公開カタログのcommit/PR/squashへ正確に引き継ぐ。
- 許可根拠: 音声機能と自動制作・公開の実装許可、Claudeの共同編集者表示の依頼、および「引き続き作成を進めてください」「利用制限に達して中断したため途中からお願いします」。新たな有料利用やアカウント設定変更は行わない。
- 開始: main `2e1e2051710449e0422a71d84753734ac95138a9` から `fix/audio-script-authorship` を作成。専用checkoutの音声合成は既存コードで継続し、起動中に差し替えない。
- 所有: 音声制作・公開の作者記録処理と回帰試験、制作の運用手順、本記録。記事本文・再生UI・他の作業の変更を戻さない。
- 方針: 原文と台本のハッシュに紐づく編集者記録を使う。独立レビューだけで作者を追加しない。Claudeが台本を実際に変更した場合に追加する。既存のClaude制作は互換性を保ち、記録が不整合な場合に虚偽の名義へ戻さない。
- 検証・終了: 単独/共同執筆、レビューのみ、writerによる変更/同一出力、旧成果物、中断時の保存順序、READY/cache/main同期と公開成功分の作者集計を確認。全体検査・独立レビュー・CI/main公開後に、現在の台本へ確認済みの作者記録を設定して制作を続ける。

## 実施結果

台本を編集した Agent を、原文と台本のハッシュに対応する追記専用の記録へ保存します。独立レビューだけ、または writer の出力が現在の台本と同一の場合は Claude を追加しません。本文を変更した場合は従来の編集者を引き継いで追加します。

作者記録を先に保存してから台本を更新し、既存台本の記録も保持します。従来の Claude 制作物の互換扱いは `authorship/` が未導入の場合に限ります。導入済みなのに空・欠損・破損している場合や、読み取りに失敗した場合は該当記事を保留にします。

レビュー済み台本と READY の再利用、公開直前、main 同期と公開再開でも対応を検査します。実際に公開できた記事の編集者だけを集計し、カタログの commit・PR・squash に同じ名義を記載します。公開カタログのデータ形式は変更していません。
