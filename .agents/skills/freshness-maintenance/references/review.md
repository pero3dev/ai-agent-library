# 定期更新の独立レビュー

対象は渡された候補の本文差分と一次資料です。編集した実行とは別の読み取り専用実行として、元記事・更新後・資料本文を確認してください。書式の再検査より、主張の正しさと関連する推奨の整合性を優先します。

- 出典は公式資料か。本文を開いて、変更した主張を直接裏付けているか。
- 対象モデル ID、プラン、地域、版、preview / GA、料金条件を省略していないか。
- 発表日、適用予定日、実施確認を混同していないか。
- 周辺の比較表、チェックリスト、research、関連記事と矛盾しないか。
- published を維持し、本文無変更の記事の更新日を進めていないか。
- 法的適用判断・ライセンス解釈・セキュリティ推奨の実質変更を通常更新へ混ぜていないか。

ファイル・行・重要度・理由・修正案を返します。最終判定は `approved` または `changes_requested`、自動マージ可否は `low` または `requires-human` です。判定対象の content digest、あなた自身の実行 ID、レビュー時刻を返してください。編集者の自己申告をそのまま独立確認済みにせず、未確認の資料はその旨を報告します。
